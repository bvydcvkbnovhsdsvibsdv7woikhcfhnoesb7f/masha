Можно кидать JSON-файлы переписки (Telegram, Qwen) или собранный masha-archive.json.gz. Повторная загрузка того же файла ничего не дублирует.

Как поднять свой релей за 5 минут (Cloudflare, бесплатно, работает в РФ)
  1. Открой dash.cloudflare.com → раздел Compute → Workers & Pages → Create → Worker (прямая ссылка: dash.cloudflare.com/?to=/:account/workers-and-pages). Страница API Tokens не нужна — там релея не создать.
  2. Имя masha-relay → Deploy (сначала будет заготовка «Hello World»).
  3. Edit code → удалить весь код → вставить worker/worker.js → Deploy.
  4. Settings → Variables and Secrets → Add → тип Secret: имя DEEPSEEK_API_KEY, значение — ключ DeepSeek.
  5. Открой адрес воркера в обычной вкладке (не в панели Preview) — ждём "hasKey":true.
  6. Вставь адрес сюда и нажми «Сохранить серверы» → «Проверить».

GitHub Pages для релея не подходит: это статический хостинг, он не умеет запускать серверный код, поэтому /api/relay на нём всегда 404. Ключ DeepSeek нельзя вшивать в страницу — репозиторий публичный.

Ответ {"error":"Error","message":"Token and remote not found"} — воркер создан как проект с Git/Artifacts-сборкой. Создай новый через Create → Start with Hello World (без «Connect to Git») и вставь тот же код.
