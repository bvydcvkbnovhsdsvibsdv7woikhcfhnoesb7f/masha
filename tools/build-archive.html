    Готово

    Архив кладётся в память приложения через «Настройки → Импорт архива», индекс ускоряет поиск по старым сообщениям.

    Что понимает инструмент

    • array — [{"role":"user","content":"...","ts":1699999999}]
    • messages / Telegram — result.json с полями from, date, text (строка или массив фрагментов)
    • qwen — экспорт чата Qwen: [{"chat":{"messages":[{"role","content","content_list","timestamp"}]}}]
    • export — наш собственный архив: {"v":1,"messages":[["user",1699999999,"текст"]]}
    Роли: user/human/me/я/вы/Эдуард → «он», assistant/bot/ai/model/Маша → «она», остальные пропускаются.
