Готовый архив памяти для приложения.

Положи сюда файлы:
  masha-archive.json.gz  — сам архив переписки (его собирает tools/build-archive.html)
  masha-index.json.gz    — готовый индекс ключевых слов (необязательно, но с ним
                           телефону не нужно строить индекс самому)

Тогда сборка APK упакует их внутрь приложения, и при первом запуске память
восстановится автоматически, без интернета и без ручного импорта.

Оба файла создаются инструментом tools/build-archive.html (открывается двойным
кликом, работает офлайн) или командой:

  node tools/build-archive.mjs --in файл1.json файл2.json \
       --out archive/masha-archive.json.gz --index archive/masha-index.json.gz
