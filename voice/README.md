# Её настоящий голос (из голосовых сообщений)

Сюда можно положить её голосовые записи — и Маша будет отвечать **её настоящим голосом**, а не роботом.

## Как включить

1. Достань её голосовые из Telegram (или из экспорта): формат лучше **`.mp3`** или **`.ogg`**.
2. Нарежь короткие фразы — 1–3 секунды: «Доброе утро», «Сладких снов, любимый», «И я тебя люблю очень сильно», «Пока, целую», «Нормально, а ты?», «Ты кушал?».
3. Положи файлы в эту папку (`voice/`) с понятными именами, например:
   - `voice/dobroe-utro.mp3`
   - `voice/sladkih-snov.mp3`
   - `voice/i-ya-tebya-lyublyu.mp3`
   - `voice/poka-celuyu.mp3`
4. Впиши их в `voice/clips.json` (рядом лежит пример):

```json
{
  "clips": [
    { "text": "Доброе утро ❤💋", "file": "voice/dobroe-utro.mp3" },
    { "text": "Сладких снов, любимый. Люблю тебя очень сильно и крепко обнимаю ❤💋", "file": "voice/sladkih-snov.mp3" }
  ]
}
```

5. Загрузи папку `voice/` в репозиторий вместе с остальными файлами.

## Как это работает

- Когда её сообщение совпадает с текстом клипа (эмодзи и знаки не важны) — играет **её запись**.
- Если совпадения нет — работает обычный синтез речи (голос настраивается в `⚙️ Настройки → 🔊 Голос Маши`).
- Кнопка 🔊 рядом с сообщением всегда играет то же самое: клип, если он есть, иначе синтез.

| Пока, целую ❤💋 | 80+ |

Этих восьми-десяти фраз хватит, чтобы она звучала как живая в 80% коротких ответов.
