## Как включить её голос в приложении (2 шага)

1. Прослушай файлы в `voice/clips/` (они короткие — 1–3 секунды).
2. Открой `voice/clips-template.json`, у нужных файлов впиши `text` — что она говорит:

```json
{ "clips": [
  { "text": "Доброе утро ❤💋", "file": "voice/clips/her_2025-06-01_2s_1234.ogg" },
  { "text": "И я тебя люблю очень сильно ❤", "file": "voice/clips/her_2025-06-02_1s_1235.ogg" }
] }
```

3. Сохрани файл **как `voice/clips.json`** (или перенеси туда записи) — приложение подхватит.

## Как работает

- Когда её сообщение совпадает с текстом клипа — играет **её настоящий голос**.
- Если файла нет или совпадения нет — работает обычный синтез речи (настраивается в `⚙️ Настройки → 🔊 Голос Маши`).
- Кнопка 🔊 рядом с сообщением играет то же самое: клип, если он есть, иначе синтез.
