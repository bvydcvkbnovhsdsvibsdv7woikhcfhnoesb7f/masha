# Её голос через XTTS на твоём ПК (Путь 1) — пошагово

Итог: Маша будет озвучивать **любой текст** её клонированным голосом.
Всё бесплатно, никаких ключей и аккаунтов.

**Время:** 15–25 минут (в основном скачивание модели ~2 ГБ).
**Где:** на твоём компьютере (Python у тебя уже стоит).

---

## Шаг 1. Установить движок (один раз, 5–15 минут)

1. Открой папку `C:\Users\Эдуард\Downloads\masha-fixed\voice`.
2. Найди файл **`УСТАНОВКА-XTTS.ps1`**.
3. Правой кнопкой → **«Выполнить с помощью PowerShell»**.
   Если Windows ругается на политику — открой PowerShell и выполни:
   ```powershell
   powershell -ExecutionPolicy Bypass -File "C:\Users\Эдуард\Downloads\masha-fixed\voice\УСТАНОВКА-XTTS.ps1"
   ```
4. Скрипт сам:
   - проверит Python,
   - создаст отдельное окружение `.venv-tts` (систему не тронет),
   - поставит `coqui-tts` + fastapi + uvicorn + soundfile,
   - проверит, что движок виден.

✅ **Ожидаемо в конце:** зелёное «ГОТОВО!» и подсказки.

❌ **Если ошибка про C++ Build Tools:** скачай
https://visualstudio.microsoft.com/visual-cpp-build-tools/ → отметь
«Desktop development with C++» → установи → повтори шаг 1.

---

## Шаг 2. Запустить сервер голоса

1. В той же папке `voice` найди **`ЗАПУСК-XTTS.ps1`**.
2. Правой кнопкой → **«Выполнить с помощью PowerShell»**.
3. Первый запуск скачает модель XTTS v2 (~2 ГБ) — подожди, это нормально.
4. Дальше скрипт **сам соберёт образец её голоса** из 8 фрагментов
   в `voice/клонирование/` (около 25 секунд чистой речи).

✅ **Ожидаемо в консоли:**
```
[xtts] образец голоса собран: 24.3 сек → ...\voice\клонирование\reference.wav
[xtts] загружаю модель XTTS v2 (первый раз это долго)…
[xtts] модель готова
[xtts] слушаю http://127.0.0.1:8788
```

⚠️ **Окно не закрывай** — это её голос. Остановить: Ctrl+C.

---

## Шаг 3. Проверить голос без приложения (1 минута)

Открой **второе** окно PowerShell и выполни:

```powershell
curl.exe -X POST http://127.0.0.1:8788/tts -H "Content-Type: application/json" -d "{\"text\":\"привет, это мой голос\"}" --output test.wav
```

Открой `test.wav` (в папке, откуда запускал) — должна зазвучать её речь.
Если слышишь её голос — всё, самое сложное позади.

## Шаг 4. Включить локальный релей

Приложение не может само позвать `127.0.0.1:8788` — это делает **локальный релей**
(он уже умеет проксировать озвучку).

1. Открой PowerShell.
2. Выполни:
```powershell
$env:DEEPSEEK_API_KEY="sk-твой-ключ"
cd C:\Users\Эдуард\Downloads\masha-fixed
python worker/local-relay.py
```
3. Ожидаемо: `локальный релей слушает http://127.0.0.1:8787` (или похожее).

⚠️ Оставь и это окно открытым. Два окна: XTTS + локальный релей.

## Шаг 5. Включить в приложении

1. Открой сайт Маши **на этом же компьютере** (важно: `127.0.0.1` работает только на нём).
2. ⚙️ **Настройки** → убедись, что в серверах есть строка `http://127.0.0.1:8787` и «Проверить» зелёное.
3. Раздел **🔊 Голос Маши**:
   - включи **«Озвучивать её голосом (клонированным, через релей)»**;
   - под галочкой должна быть зелёная строка **«Голос на релее: local»**.
4. Напиши ей что-нибудь и нажми 🔊 — она ответит её голосом.

## Важные ограничения (честно)

1. **Голос работает, пока открыты два окна** (XTTS + локальный релей) и ПК включён.
2. **На телефоне через мобильный интернет не сработает** — `127.0.0.1` это сам телефон.
   Чтобы работало везде, нужен туннель (см. ниже) либо облачный путь (ElevenLabs).
3. **Скорость:** CPU-озвучка ~1–3 секунды на короткую фразу. Если ПК слабый — может быть 5–10 сек.
4. **Качество** зависит от образца: у нас 8 фрагментов, 24 секунды — этого достаточно, но
   если хочешь идеал, дай больше её чистой речи (30–60 секунд) в `voice/клонирование/`.

---

## Если хочешь, чтобы голос работал и на телефоне

Нужно «выставить» сервер голоса наружу. Бесплатно через Cloudflare Tunnel:

1. Скачай `cloudflared` для Windows: https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/
2. Выполни:
```powershell
cloudflared tunnel --url http://127.0.0.1:8788
```
3. Он выдаст ссылку вида `https://xxxx.trycloudflare.com`.
4. Замени в `voice\ЗАПУСК-XTTS.ps1` ничего не нужно — вместо этого задай в локальном релее:
```powershell
$env:LOCAL_TTS_URL="https://xxxx.trycloudflare.com/tts"
```
5. Тогда озвучка пойдёт через интернет — и заработает с телефона (если локальный релей тоже доступен).

> Скажи, если нужен этот вариант — распишу подробнее.

## Частые ошибки

| Что видишь | Что делать |
|---|---|
| `pip install` падает на `torch` | Поставь C++ Build Tools (см. шаг 1), потом повтори |
| `numpy` конфликт | `pip install "numpy<2"` в окружении `.venv-tts` |
| `[xtts] не смог собрать образец` | Проверь, что в `voice/клонирование/` есть `.ogg` файлы |
| `Connection refused 8788` | Не запущен `ЗАПУСК-XTTS.ps1` |
| `Голос на релее не настроен` | Не запущен `local-relay.py` или он не видит 8788 |
| Звук хрипит/рвётся | Уменьши текст (озвучивай по фразе) или дай ПК больше памяти |
| Долго думает | Первая фраза всегда медленнее (модель прогревается) |
