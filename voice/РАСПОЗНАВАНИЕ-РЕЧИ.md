# Распознавание речи (голосовые) — варианты

Приложению нужен движок, который превращает голос в текст. DeepSeek этого не умеет,
поэтому движок подключается к релею. Поддерживаются **четыре** варианта — выбери любой,
работает первый доступный (порядок именно такой):

## 1. Cloudflare Workers AI — самый простой и бесплатный ⭐

Ты уже используешь Cloudflare, поэтому это лучший вариант: новый аккаунт не нужен.

1. dash.cloudflare.com → **Workers & Pages** → твой воркер.
2. **Settings** → **Bindings** (или «Bindings and Variables»).
3. **Add binding** → **Workers AI** → имя обязательно **`AI`** → Save.
4. **Deploy** (перезалить код воркера тоже нужно, если ещё не перезалит).
5. Проверить: открыть адрес воркера в браузере → в ответе должно быть `"stt":"cloudflare"`.

Бесплатный лимит: 10 000 Neurons в день — для голосовых сообщений это очень много.

## 2. Groq — бесплатный ключ

1. console.groq.com → API Keys → Create.
2. Cloudflare → воркер → Settings → Variables and Secrets → **Add** → тип **Secret**:
   имя **`GROQ_API_KEY`**, значение — ключ. → **Deploy**.
3. В диагностике будет `"stt":"groq"`.

## 3. Hugging Face — бесплатный токен

1. huggingface.co → Settings → Access Tokens → New token (read).
2. Секрет **`HF_TOKEN`** в воркер → Deploy.

## 4. OpenAI Whisper — платный

Секрет **`OPENAI_API_KEY`** в воркер → Deploy.

## 5. Локальный Whisper (полностью офлайн, без ключей)

Если хочешь, чтобы распознавание работало без интернета и без аккаунтов — на своём ПК:

```
pip install faster-whisper
```

Локальный релей (`worker/local-relay.py`) сам подхватит его и будет распознавать
голосовые офлайн. Модель `small` скачается при первом использовании (~500 МБ).

## Что если ничего не настроить

Всё остальное работает. Она получает голосовое и реагирует на него как на голосовое
(«ты чо шепчешь», «скажи ещё»), просто не понимает слов внутри.

## Проверка

Отправь ей голосовое. Если распознавание работает — она ответит по смыслу сказанного.
Если нет — покажет подсказку, чего не хватает.
