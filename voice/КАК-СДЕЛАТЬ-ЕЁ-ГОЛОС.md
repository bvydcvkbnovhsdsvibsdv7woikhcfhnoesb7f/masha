# Как сделать, чтобы она говорила своим голосом

Три пути. Первый — самый точный и бесплатный, но требует 10 минут установки на ПК.
Второй — быстрый, с сервисом. Третий — уже работает (её реальные записи).

---

## Путь 1. Клонирование на своём ПК (XTTS v2) — ЛЮБОЙ текст её голосом, бесплатно

Это лучший вариант: голос клонируется по её реальным ГС, а озвучить можно **любую фразу**.

### Установка (один раз)

1. Нужен Python 3.10+ (у тебя уже есть Python 3.11).
2. Открой PowerShell и выполни:

```powershell
pip install TTS fastapi uvicorn soundfile
```

Модель скачается при первом запуске (~2 ГБ).

### Запуск

```powershell
cd C:\Users\Эдуард\Downloads\masha-fixed
python tools/xtts-server.py
```

Ждём в консоли: `[xtts] слушаю http://127.0.0.1:8788`
Образец голоса берётся из `voice/клонирование/` — там уже лежат 8 её фрагментов.

### Подключение к приложению

1. Открой **Cloudflare** → воркер → **Settings** → **Variables and Secrets** → **Add**:
   - тип **Secret/Text**: имя **`LOCAL_TTS_URL`**, значение `http://127.0.0.1:8788/tts`
2. **Deploy**.
3. В приложении: **⚙️ Настройки → 🔊 Голос Маши** → включи **«Озвучивать её голосом (клонированным, через релей)»**.
4. Напиши ей что угодно и нажми 🔊 — она заговорит клонированным голосом.

> ⚠️ Ограничение: сервер работает на твоём ПК. Если компьютер выключен — озвучка
> падает на обычный синтез. Для работы «всегда» нужен облачный вариант (Путь 2).

## Путь 2. Облачное клонирование (работает всегда, без ПК)

### ElevenLabs
1. elevenlabs.io → регистрация (бесплатно ~10 000 символов в месяц).
2. **Voices → Add voice → Instant Voice Cloning** → загрузи 3–8 файлов из `voice/клонирование/` → имя «Маша».
3. Скопируй **Voice ID** (в карточке голоса).
4. В Cloudflare добавь два секрета:
   - `ELEVENLABS_KEY` — твой API key (Profile → API Keys)
   - `ELEVENLABS_VOICE_ID` — ID голоса
5. Deploy → включи галочку в приложении.

### Fish Audio
1. fish.audio → Create model → загрузи фрагменты → получишь `reference_id`.
2. Секреты в Cloudflare: `FISH_KEY`, `FISH_VOICE_ID`.
3. Deploy → включи галочку.

## Путь 3. Её реальные записи (уже работает, без ключей)

В `voice/clips/` лежат 108 её коротких голосовых. Приложение уже умеет проигрывать
её настоящий голос, когда фраза совпадает с записью.

Чтобы подписать их **автоматически** (нужна включённая распознавалка на релее):

```powershell
cd C:\Users\Эдуард\Downloads\masha-fixed
node tools/transcribe-voice.mjs https://masha.lusnikoveduard9.workers.dev
```

Скрипт распознает все 439 её ГС, создаст `voice/clips.json` с реальными фразами
и подписями. После загрузки в GitHub она будет отвечать **её настоящим голосом**
на всё, что попало в записи.

## Как проверить, что голос работает

В Настройках под галочкой есть строка статуса:
- **«Голос на релее: local / elevenlabs / fish — …»** — всё готово;
- **«не настроен»** — не добавлены секреты или не сделан Deploy.

Проверка прямо в браузере: открой адрес воркера — в ответе должно быть поле
`"tts":"local"` (или `elevenlabs` / `fish`).
