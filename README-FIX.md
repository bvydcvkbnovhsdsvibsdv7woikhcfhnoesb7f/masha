## 2. Способ 1: локально, проверить прямо сейчас (2 минуты)

Node.js у тебя не установлен, а **Python есть** — релей запускается так
(PowerShell, из папки проекта):

```
cd путь\к\masha-fixed
$env:DEEPSEEK_API_KEY="sk-твой-ключ"
python worker/local-relay.py
```

Увидишь `Адрес для приложения: http://127.0.0.1:8787`. В приложении:
**Настройки → 🛰️ Серверы Маши** → вписать `http://127.0.0.1:8787` → **Сохранить серверы** →
**🔍 Проверить** (должна быть зелёная галочка). Работает и с сайтом на GitHub Pages:
браузер разрешает обращаться к `127.0.0.1` даже со страницы по https.

Так можно убедиться, что вся связка «приложение → релей → DeepSeek → память» живая,
ещё до всякого хостинга: ключ уходит напрямую в DeepSeek, никуда больше.

> Есть и вариант на Node.js (`node worker/local-relay.mjs`), если когда-нибудь поставишь Node.

## 3. Способ 2: Cloudflare Worker (постоянно, бесплатно, работает в РФ)

1. **dash.cloudflare.com** → раздел **Compute** → **Workers & Pages** → **Create** → **Worker**.
   Прямая ссылка: `https://dash.cloudflare.com/?to=/:account/workers-and-pages`
   (страница **API Tokens** не нужна — там релея не создать).
2. Имя **masha-relay** → **Deploy** (сначала появится заготовка «Hello World» — это нормально).
3. **Edit code** → удалить весь код → вставить **весь** файл `worker/worker.js` → **Deploy**.
4. **Settings → Variables and Secrets → Add** → тип **Secret**: имя `DEEPSEEK_API_KEY`,
   значение — ключ DeepSeek → **Save**.
5. Открой адрес воркера **в обычной вкладке браузера** (не в панели Preview):
   `https://masha-relay.ТВОЙ-ЛОГИН.workers.dev` → ждём
   `{"ok":true,"service":"masha-relay",...,"hasKey":true}`.
6. Вставь этот адрес в **Настройки → 🛰️ Серверы Маши** → **Сохранить** → **Проверить**.

### Если что-то не так

| Что видишь | Что делать |
|---|---|
| `"hasKey":false` | секрет не сохранился — вернись к шагу 4 |
| страница «Hello World» | код воркера не заменился — вернись к шагу 3 |
| `{"error":"Error","message":"Token and remote not found"}` | воркер создан как проект с Git/Artifacts-сборкой: создай новый через **Create → Start with Hello World** (без «Connect to Git») |
| `ERR_NAME_NOT_RESOLVED` | адрес не существует: скопируй его из **Settings → Domains & Routes** (поддомен `workers.dev` создаётся один раз на аккаунт). Если не помогает и с мобильного интернета — `workers.dev` блокируется провайдером, используй способ 3 или 4 |
| `✗ ... — ответил HTML вместо JSON` | по адресу лежит сайт, а не релей (например GitHub Pages) |

## 4. Способ 3: Deno Deploy (тоже бесплатно, другой домен — `*.deno.dev`)

1. **dash.deno.com** → войти через GitHub → **New Playground**.
2. Вставить целиком файл `worker/deno-relay.js` → **Save & Deploy**.
3. **Settings → Environment Variables** → `DEEPSEEK_API_KEY` = ключ → сохранить.
4. Адрес вида `https://имя.логин.deno.dev` → вставить в приложение (как в шаге 6 выше).

## 5. Способ 4: Netlify Functions или Vercel

- **Netlify**: файл `worker/netlify-relay.js` кладётся как `netlify/functions/relay.js`,
  адрес релея — `https://ИМЯ.netlify.app/.netlify/functions/relay`,
  ключ — в Site configuration → Environment variables.
- **Vercel**: файл `api/relay.js` уже лежит на месте, адрес `/api/relay`,
  ключ — Settings → Environment Variables → `DEEPSEEK_API_KEY` → Redeploy.
  (У тебя Vercel не отвечал — возможно, блокируется провайдером.)

Адресов можно указать несколько — приложение перебирает их по порядку, запоминает
рабочий и само переключается, если первый лёг.

## 8. Как проверить, что всё работает

```
python tools/check-key.py                      # ключ DeepSeek: рабочий ли он, баланс, какие модели доступны
python tools/test-vision.py                    # видит ли модель фото (проверено: deepseek-flash видит)
node --test test                               # 38 тестов: память, Telegram, релей, интерфейс
node tools/check-archive.mjs --max 60000       # что Маша вспомнит на живые запросы
node tools/check-archive.mjs                   # то же на полном архиве
node tools/build-archive.mjs --in source/*.json \
     --out archive/masha-archive.json.gz --index archive/masha-index.json.gz
```

`check-archive.mjs` печатает найденные эпизоды с датами — например, на запрос
«как дела с тренировками» находит «а щас меня заставляют какую то тренировку для
похудения делать» (09.09.2024), а на «у меня болит голова» — реальные эпизоды
с головной болью из января 2025.
